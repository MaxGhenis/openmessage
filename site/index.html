outbox

Sends you can trust

Every send is a durable intent. If the network drops mid-send, OpenMessage knows the difference between 'never went out' and 'might have' — and says so. Ambiguous sends wait for the transport's own confirmation. Send again is an explicit choice, never an automatic retry. No lost messages. No double-sends.

supervisor

Connections that heal

Each platform connection runs under a supervisor that reconnects with backoff, repairs expired credentials, and parks cleanly when something needs you. When wifi blips, the app reconnects and moves on — you hear about it only when something genuinely needs you.

sqlite

Local-first, actually

Your entire message history is one SQLite file in your Application Support folder. Search is instant and offline. Nothing syncs anywhere unless you send it.

file ~/Library/Application Support/OpenMessage/messages.db
mcp

Built for the AI era

OpenMessage ships an MCP server: your AI tools can search conversations, send messages, and schedule sends — with the same reliability guarantees as the UI. And the app itself is built at the frontier: designed, implemented, and adversarially reviewed by AI agents, every merge gated by tests and review.
